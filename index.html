❓ 帮助中心 ▼
🚀 快速入门
  1. 上传简历 — 在设置中上传你的简历（.docx / .txt / .md），AI 将根据简历内容出题
  2. 配置 API — 填写 API Key、模型、API 地址（详见下方配置指南），或直接使用本地模板
  3. 智能练习 — 输入面试问题或快速选题，AI 根据简历生成个性化回答
  4. 模拟面试 — 启动 5 题模拟面试，支持文字/语音/视频三种模式，结束后生成评分报告
  5. 追问树 — 回答后自动生成 2-3 层追问，模拟面试纵深压力

🔍 常见错误排查
错误原因解决方法
401 Unauthorized API Key 无效或未授权 检查 Key 是否正确、是否过期；确认 Base URL 与 Key 的提供商一致
CORS / 跨域错误 用 file:// 打开页面 使用本地服务器：python -m http.server 3458，然后访问 http://localhost:3458
404 Model Not Found 模型名称不对 对照上表填写正确的模型名（如 DeepSeek 用 deepseek-chat，非 gpt-4o-mini）
400 Bad Request 请求格式错误（模型名错/参数缺失） 检查模型名是否正确、是否为空；对照帮助中心表格确认该提供商的推荐模型名
402 Payment Required / Insufficient Balance 账户余额不足或需付费 登录 API 提供商平台充值或领取免费额度（DeepSeek/千问/硅基流动新用户均有赠送）
返回内容为空 API 未正确响应 检查网络连接；确认 Base URL 末尾不要有多余路径；用「测试连接」按钮验证
回答没有根据简历 未配置 API，使用本地模板 配置上方 API Key 后重新生成
